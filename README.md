# Tiler

A tiny local macOS menu bar app that snaps your windows into custom layouts.
Define tiles (as fractions of a screen), map apps to tiles, and apply a layout
from the menu bar or a global hotkey. Built for ultrawide screens, works with
any number of displays.

## 🏗️ Building method

This app was vibe coded as a simple personal local utility with the Claude Fable model. It does not communicate with any external services or save any credentials. It has been reviewed thoroughly for security risks. To make the app work, it ofcourse needs to access your monitor.

## ⚡️ How it works

1. Download the release
2. Open the app (maybe you have to allow the app through the security settings)
3. Allow the app accessibility
4. A menu bar item now appears, where you can set and activate layouts.

## 🎹 Hotkeys

Use the `^ + ⌥ + [Arrow key]` to move the focused window to another slot.
